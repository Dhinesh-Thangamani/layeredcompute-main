# PCIe Multi-Segment

# Overview
Ability to create multiple PCIe bus hierarchy is called Multi-segment PCIe. The PCIe hierarchy may contain maximum of 256 buses. In the ever growing number of devices in server systems, one PCIe hierarchy may not be enough. To bridge the resource contraint caused by the PCIe single segment, multi-segment has been introduced. More than one PCIe segment is supported. It is also known as PCIe Domain.
