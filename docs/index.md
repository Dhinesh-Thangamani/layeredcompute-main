# Home

Multi-Layered Intelligence

Computer features spanning the complete solution stack, from silicon to the operating system. The focus is on how hardware, firmware, and OS components work together, and how industry-standard interfaces and specifications are used to build the system. Emphasis is placed on system architecture and practical implementation details.

## Industry Standards

* x86 CPU Architecture
* PCI - Peripheral Component Interconnect
* PCIe- Peripheral Component Interconnect Express
* I2C - Inter Integrated Circuit
* SPI - Serial Peripheral Interface
* eSPI- Enhanced Serial Peripheral Interface
* UART- Universal Asynchronous Receiver Transceiver
* UEFI- Unified Extensive Firmware Interface
* ACPI- Advanced Configuration Power Management
